# 一年薄肌计划 PWA · 第二版

## 部署到现有 GitHub Pages
1. 解压 ZIP。
2. 打开 GitHub 仓库 `thin-muscle-plan`。
3. 在仓库根目录上传并覆盖 `index.html`、`manifest.json`、`sw.js`。
4. 等待 GitHub Pages 更新后，用 iPhone Safari 打开原来的 Pages 地址。
5. 如旧版本仍显示，关闭网页重新打开；必要时从主屏幕移除旧图标后重新添加。

## iPhone 添加到主屏幕
Safari 打开网页 → 分享 → 添加到主屏幕。

## 本版功能
- 今日 / 历史 / AI分析三大页面
- BMR、TDEE、每日目标摄入、目标热量缺口估算
- 早餐、午餐、晚餐图片与营养记录独立分类
- 身材照片独立归档，可选上传
- 图片压缩后保存在 IndexedDB 本地数据库
- 训练动作完成勾选；长按动作文本编辑（桌面端可右键/双击）
- 晨起体重、疲劳、身体反馈、每日总结
- 每日22:00应用内提醒：打开应用时检查；不具备应用关闭后的可靠系统推送
- HTML报告内嵌实际上传图片；PDF通过浏览器打印界面保存
- JSON完整备份/恢复、CSV导出
- 基于本地记录生成下一周训练草案

## 重要说明
- 自动图片AI营养识别尚未接入。可先手动填写AI或自行估算后的营养数据。
- iOS后台推送需要额外推送服务端，本版没有伪装成已实现。
- 数据保存在当前设备浏览器。清除Safari网站数据、卸载浏览器或更换设备前请先导出完整JSON备份。
- 不要将真实个人照片或备份文件上传到公开GitHub仓库。
- PDF保存：点击“打印/保存PDF”，在系统打印预览中使用分享按钮或存储到文件。
